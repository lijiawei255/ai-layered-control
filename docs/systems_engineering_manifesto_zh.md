# 系统工程宣言：快慢分层控制架构与确定性安全边界

这套架构要回答的核心问题是执行器的控制权归谁。答案是分工：慢环语义模型负责选择工况，确定性控制器负责连续控制量、积分修正与故障恢复。这样划分之后，“学习环境描述”与“在扰动下维持物理不变量”成为两个独立问题，可以分别设计、分别验证。

目前有三条路线并存。白盒控制器把标称逆动力学、反馈与抗积分饱和组合在一起，在熟悉工况下表现很强；但单组固定增益必须同时在扰动抑制、接触柔顺与噪声放大之间取舍，照顾一头就要牺牲另一头。快慢学习控制器把上下文推理与连续动作头分开，动作头以快环频率运行，感知时延因此不进入执行器通路；代价是它的局部映射取决于训练数据所覆盖的动力学，数据没有覆盖的工况就没有保证。分层路线把工况选择交给慢环接口，把定量反馈交给确定性控制库：积分状态吸收持续偏差，物理旋钮在部署后仍然可调，残差探针可以拒绝未知工况。慢环接口与具体模型解耦，无论原型分类器、规则监督器还是 VLM，都可以实现同一份契约。传统增益调度或固定阈值规则树只切分已知工况，在遭遇未建模机械谐振或分布外（OOD）扰动时，仍会盲目输出最近档位的控制律。不同于仅在安全边界拦截连续 AI 指令的传统 Simplex / 运行时保障（RTA）外壳，本架构从接口上剥离慢环的连续执行权，通过快慢双层主动弃权将控制权边界固化为跨环接口契约：10 Hz 慢环执行流形距离低置信度弃权并退守 R4 阻尼，1 kHz 快环则依据独立物理残差探针执行毫秒级强制否决。

## 分层系统边界（L0–L4）

| 层级 | 职责 |
| :--- | :--- |
| L0 | 硬件安全通道：独立安全 PLC（ISO 13849 Cat.3/4，1oo2D）、双通道传感器交叉校验、硬件 STO / IEC 60204-1 Stop 0。 |
| L1 | 确定性快内环：四档 PID，全分支反向追踪抗积分饱和 + 标称前馈；DOB/ESO/ADRC 或有界自适应补偿可加入控制律槽位或经 `u_ff` 注入。 |
| L2 | 运行时安全仲裁与降级链：96 B C99 Simplex 状态机、1D ZCBF 有符号包络前瞻、消隐保持、逐轴 R4 → SAFE_ZERO → LATCHED_SAFE；多轴聚合 `gate_state` 加共享 ack 总线实现 Stop 1/2。（按 ISO/IEC TR 5469：物理行程/力矩/斜率/超时均为先验精确不等式，且须规避主控 AI 与监督 AI 在分布外同时盲目外推的共因失明，故本层必须由确定性代码而非第二个黑盒模型承担。） |
| L3 | 慢环定性监督与校准弃权：10 Hz 离散工况建议 + 校准的距离置信度。 |
| L4 | 设备群全生命周期闭环：运行期冻结 AI 权重、只追加的 7 位故障审计掩码作为 OOD 数据采集触发标签、离线原型补充与安全案例更新。 |

## 六个现场问题与对应机制

### 1. 样本稀缺与连续策略的算力开销

**工程问题：** 连续动作模型依赖密集标注轨迹。本基准中，代表快慢学习路线的条件 RBF 动作头（B2）使用 16,000 条标称仿真样本训练。如图 2 Panel A 所示，其标称 RMSE 在 64–1,024 样本时已经收敛，但因为缺少快环安全门控，它仍无法消除 S4 越界。16,000 条标签是仿真实验设置，量化的是密集采样的工程代价。

**传统定参控制与纯 AI 路线的局限：** 面对样本稀缺，在目标机台上重训是自然反应，但数据成本与试错风险会随每台设备、每种工况放大。固定规则树不需要标签，却表达不了随工况变化的连续动力学。两条路卡在同一个地方。

**本架构机制：** 连续定量反馈与轨迹跟踪已由先验整定的 4 档确定性控制器与标称前馈承担，10 Hz 慢环只需负责粗粒度离散工况分类与流形距离弃权，因此只需要定性覆盖：36 个标注宏观窗口、15 个统计标量（60 B），由 `auto_calibrate()` 在 CPU 上完成建档。档案给出工况原型与置信度阈值，全程不需要 GPU，也不需要动作标签。模板内置的 15 个统计标量最近质心分类器与 6 点受约束搜索（`auto_field_tune`）作为基于 NumPy、无需机器学习框架的紧凑实现，在实际工程中可按同一接口直接替换为带超界兜底分支的物理规则树、安全贝叶斯优化或其它分类模型。B2 在此作为对照，用来量化连续路线的数据代价：它需要在每个 1 ms 周期评估 **5,664 个标量 / 22,656 B** 的连续动作头，而本架构只要在 10 Hz 上完成离散工况分类与流形距离置信度，模型仅 **15 个统计标量 / 60 B**——慢环任务从 1 kHz 连续回归降维为 10 Hz 离散分类，样本建档与在线推理算力同时降到极低水平。

### 2. 多工况冲突：静摩擦与柔顺接触

**工程问题：** 同一项任务既要在重载下打破静摩擦，又要在单边接触时让出位置；这两个目标把同一组增益拉向相反方向，一组定参无法同时满足。

**传统定参控制与纯 AI 路线的局限：** 定参白盒基线 B1 与分层支路 B3 共享完全相同的标称逆动力学前馈、抗积分饱和与限幅。B1 取得全场最低的 S2 原始 RMSE 0.017125 rad，但定参带来水床效应：S3 撞墙时接触力达到 64.59 N；即便加入相同的 alpha = 0.3 输出低通，仍有 63.47 N，6 个候选调参全部不满足接触约束。

**本架构机制：** 底层设置 R1..R4 四档确定性控制库：R1 标称、R2 重载、R3 柔顺接触、R4 安全回退。活动档的积分器在 blend 滤波之前按幅值/斜率限幅后的指令反向计算，非活动档跟踪实际施加的指令，因此档位切换不会释放隐藏的积分能量。当否决激活或永久锁存切入 R4 时，内核旁路 blend_alpha，直接令 blend = 1.0，紧急阻尼在第一个 tick 就生效，不受一阶无扰切换延迟的影响。

### 3. 未知流形与亚健康振荡

**工程问题：** 新装设备可能运行在标定流形之外。基准测试工况以正常幅值运行，叠加盒内耦合常值负载偏置与 1% 逐帧分裂共形误报预算（5 帧持续性）；一旦工作点离开标定流形，回路不能继续施加“看起来自信”的指令。

**传统定参控制与纯 AI 路线的局限：** 本基准所对比的固定阈值规则树（未额外内嵌显式流形距离或密度模型）与模糊控制只编码决策边界，没有“距标定分布多远”的概念。物理规则树与原型分类器在主表 S1/S2 决策和 19.9 N 的 S3 接触峰值上完全一致，但在 OFF_MANIFOLD 工况下无法弃权——弃权需要先回答“当前特征点离已知运行区域有多远”，而规则树给不出这个度量。

**本架构机制：** 原型模型把 `ai_confidence` 作为基于流形距离的置信度输出。一旦离开流形，置信度塌缩，触发低置信度主动弃权：1 kHz 内核记录 GATE_VETO_LOW_CONFIDENCE，并以固定阻尼运行 R4，直到重新得到可信的正常工况为止。传统分层控制只因缺少流形距离度量，就只能在已知工况间硬选最近档位、无法区分低置信度与未知工况；本架构的流形距离让主动弃权成为可观测、可裁决的确定性事件。

### 4. 跨机台、批次与个体漂移，现场无重训算力

**工程问题：** 正向重载 +35%／+50%、交叉失配（J +40%，b -30%）、反向轻载 -25% 都会让设备偏离标称模型，而现场没有重训预算。

**传统定参控制与纯 AI 路线的局限：** 按周期重建标定档案，前提是每种工况都有一份数据集和一次训练；学习式动作头在此基础上还要额外标注。当技术员手里只有力矩扳手和秒表时，这两条路都走不通。

**本架构机制：** 设计把两个对象正交解耦：冻结的 AI 流形拓扑负责定性工况，12 B 物理旋钮 `FieldTuning_t`（`gain_scale`、`damping_scale`、`safety_margin_scale`）负责吸收定量偏差。`auto_field_tune()` 在固定增益／阻尼网格上做 6 次受约束试验，只接受同时满足负载、接触与包络约束的候选，全程冻结分类器。

### 5. 100 ms 盲区、瞬态刺激与通信断联

**工程问题：** 100 ms 盲区来自 10 Hz 慢环的上下文更新节奏：慢环每 100 ms 才看到一帧新数据。刺激脉冲、换向边沿和传感器瞬态都落在这个窗口内；链路中断还会让旧指令滞留在执行器上。

**传统定参控制与纯 AI 路线的局限：** 更慢的监督扫描只会把盲区拉得更长。B2 的 1 kHz 连续动作头虽然每毫秒读取快环状态，但其上下文特征 z 仍受 100 ms 慢环周期与传输时延约束。传输帧龄还可能被伪造或冻结；没有本地证据，回路就分不清“被控对象静止”与“慢环通信中断”。

**本架构机制：** 一支 32 B 探针以 1 kHz 运行：三点中值滤掉单 tick 毛刺，级联高通提取宽频标称模型预测残差（新息），快速建立、缓慢衰减的包络再把它归一化为无量纲残差。遇到计划内伪迹时，`blanking_active` 冻结探针全部内部滤波器状态并保持消隐前的残差（`return p->residual`）：正常周期性脉冲不会抬升残差；跨越多个消隐窗口的持续异常只计一次 OOD 锁存事件；消隐窗口之外，残差按释放包络自然衰减。96 B 内核再叠加三重保护：25 ms 有符号包络前视、独立残差否决，以及 `outer_seq` 本地时钟租约，冻结的传输帧龄无法掩盖慢环通信停滞。慢环通信帧过期但快环传感器健康时，回路保持在固定 R4 律上闭环运行；超过 `max_hold_ticks`（参考配置 100 tick）后进入 GATE_SAFE_ZERO，清空积分器，并以 `max(u_slew_max_per_s * dt_s, 1 binary32 ULP(|u_prev|))` 的每拍步长把指令降到零。正常路径严格满足 `|u(k)-u(k-1)| <= u_slew_max_per_s * dt_s`；唯一书面例外是这条向零「单 ULP 保底」：仅当合法斜率预算小于一个可表示步长时启用，只减小幅度，绝不反向注入能量。

### 6. 裸机资源死限与事故追责

**工程问题：** 控制任务要在固定内存目标的 1 kHz 中断里运行，没有堆，也没有操作系统；事故报告还必须说明，是哪次决策、哪个根因把执行器放进了安全状态。

**传统定参控制与纯 AI 路线的局限：** Python 或推理运行时会带来动态分配、调度抖动与不可追溯状态；没有持久证据的否决，回答不了事后问题。

**本架构机制：** 内核为 ANSI C99、零动态内存、静态定长状态。ABI 为 state/config/tuning/input/output 96/140/12/40/28 B，另加 32 B 探针。7 位 `fault_audit_bitmask` 记录延迟、残差流形外、低置信度、包络越界、NaN 损坏、HOLD 超时与永久锁存七类事件。累计 3 次安全／残差否决故障事件（episode）后永久锁死 GATE_LATCHED_SAFE；唯有人工调用 `Layered_AcknowledgeFaultLatch()` 才能解除锁存，在冷却期后恢复故障事件容限，并保留终身计数。

## 带宽与权限是两个独立选择

推理频率只说明指令何时生成，指令是否可执行要由另一组条件决定。完整架构必须明确规定：哪些状态估计、物理残差、执行器限制和恢复条件可以否决指令。1 kHz 确定性内核对 10 Hz 慢环执行零信任（zero-trust）仲裁：慢环输出的只是待审工况提议，数值合法性、帧龄真实性（启用 `outer_seq` 时）、物理残差包络与恢复冷却全部由快环独立核验。

门控采用固定优先级：先查状态包络，再查残差，再查置信度，最后是内核级延迟 HOLD（指令保持）。可观测状态是显式的——GATE_NORMAL、GATE_HOLD_LATENCY、GATE_VETO_OOD_RESIDUAL、GATE_VETO_LOW_CONFIDENCE、GATE_VETO_SAFETY_ENVELOPE、GATE_SAFE_ZERO 与 GATE_LATCHED_SAFE，帧龄始终可观测。驻留与恢复冷却约束重新启用的时机；反向追踪抗积分饱和让每个非活动控制器都与实际指令保持一致；每 tick 的幅值与斜率限制属于执行器契约，正常路径严格满足 `|u(k)-u(k-1)| <= u_slew_max_per_s * dt_s`。

安全回退是一种明确的控制模态，其参考目标、阻尼与前馈权限必须按设备逐一定义。慢环通信帧过期但快环传感器健康时，实测 1 kHz 回路保持在固定 R4 律上闭环运行；只有快环输入不可用时才开环保持上一条执行器指令，其物理后果由设备适配层定义。内核 R4 以固定增益、零前馈朝已标定的安全零点调节；慢环决策损坏时，只要快速测量仍然有效，这条闭环控制律就继续运行。

## 将现场适配落在可辨识的物理参数上

新设备可以沿用工况语义，同时具有不同的定量动力学。小样本建档先确定工况原型与置信度阈值；随后冻结这份档案，在相同的确定性保护下搜索有限的增益与阻尼调整；候选验收共同约束重载静摩擦误差、接触力与回退模态占比。

这样的标定记录能直接回答三个问题：哪些物理旋钮变了，试验检查了哪些约束，跟踪性能如何变化。面对全新物理领域，则要先定义信号、标称模型与控制库，再建立自己的语义档案。连续策略重训是另一项对照：采集目标机台动作标签后，分别测量标称精度、冻结迁移与恢复。

## 用实验拆开因果链

实验设计的目标是让每条因果链可以单独检验：静摩擦模型必须能在指定积分步长下真实锁止；单边接触必须同时观察接触力与位置误差；未知柔性模态需要一支不读取故障频率的宽频残差探针；噪声、上下文延迟与接触刚度应能独立调节。

对照实验中各基线均以满配状态运行。B1 与 B3 共享完全相同的标称逆动力学前馈、抗积分饱和与限幅，B1 的 S2 结果仍是表中最低的原始误差。B2 动作头以 1 kHz 全速运行（40,000 次推理，快环状态零延迟）；但它带有钳位误差积分历史特征、没有外部确定性 PID 稳定器，也没有物理门控，因此 S2 误差偏大，S3 接触力 65.71 N，S4 越界 824 tick。物理规则树与原型分类器在主表 S1/S2/S3/S4 结果（含 19.9 N 的 S3 接触峰值）上一致，但在流形外工况下规则树无法弃权。分层支路在 S4 记录 RMSE 0.534138 rad、TV 1528.1 N·m、零越界，而 B1 保持更低的 S2 原始误差；这些观测共同定义了基准的解读方式。

## 面向受约束设备的通用接口

工业 WAAM 与 PLC 伺服在慢环识别工艺与负载工况，在快环完成过程调节与执行器约束；Edge VLA 在上层处理任务与环境语义，在下层完成力矩或阻抗闭环；aDBS／SCS 闭环神经调控把生物标志物与接口状态映射到设备定义的调节律、输出包络与时序限制。三者行业不同，却是同一权限划分的并列实例。其他设备只要能定义可测状态、标称模型、明确回退与定量限制，就可以套用相同的适配顺序；多通道分别持有控制状态、探针与时间戳，耦合约束由设备适配层处理。

可复现结果与资源测量统一维护在 [README.md](../README.md)；[AGENTS.md](../AGENTS.md) 定义实现契约，[领域映射指南](domain_mapping_guide.md) 定义适配方法。
