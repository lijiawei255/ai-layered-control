# 定性 AI 与定量控制的系统分工

核心问题是执行器的控制权归属。慢环语义模型负责选择工况；确定性控制器负责连续控制量、积分修正与故障恢复。这项分工把“学习环境描述”与“维持受扰下的物理不变量”分开。

三条路线并存。白盒控制器把标称逆动力学、反馈与抗积分饱和结合起来，在熟悉工况下很强，但单组固定增益必须在扰动抑制、接触柔顺与噪声放大之间权衡。快慢学习控制器把上下文推理与连续动作头分开，动作头以快环频率运行，感知时延不进入执行器通路，但其局部映射取决于训练数据覆盖的动力学。分层路线把工况选择交给慢环接口，把定量反馈交给确定性控制库：积分状态吸收持续偏差，物理旋钮在部署后仍然可用，残差探针可以拒绝未知工况。慢环接口与具体模型解耦，原型分类器、规则监督器或 VLM 都能实现同一契约。

## 六个现场问题与对应机制

### 1. 样本稀缺、试错代价高

**问题。** 连续动作模型依赖密集标注轨迹。本基准中条件 RBF 动作头（B2）使用 16,000 条标称仿真样本训练。如图 2 Panel A 所示，其标称 RMSE 在 64–1,024 样本下已经收敛，但在缺乏快环安全门控时仍无法消除 S4 越界。此处用该样本量直观说明在真实硬件上依赖密集试错采样与重训的工程门槛，它并非实测的机时或磨损预算。

**传统与纯 AI 的失效。** 在目标机台上重训是自然反应，但数据成本与试错风险随每台设备、每种工况放大。固定规则树不需要标签，却无法表达随工况变化的连续动力学。

**机制。** 10 Hz 慢环只需要定性覆盖：36 个标注宏观窗口、15 个标量、60 B，由 `auto_calibrate()` 在 CPU 上完成档案建立。档案给出工况原型与把握度阈值，不需要 GPU，也不需要动作标签。B2 作为对照，量化连续路线的数据代价。

### 2. 多工况冲突：静摩擦与柔顺接触

**问题。** 同一任务既要在重载下打破静摩擦，又要在单边接触时让出位置；两者把同一组增益拉向相反方向。

**传统与纯 AI 的失效。** B1 与 B3 共享完全相同的标称逆动力学前馈、抗积分饱和与限幅。B1 取得全场最低的 S2 原始 RMSE 0.017125 rad，但定参水床效应使 S3 撞墙时接触力达到 64.59 N；加入相同的 alpha = 0.3 输出低通后仍有 63.47 N，6 个候选调参全部不满足接触约束。

**机制。** 底层设置 R1..R4 四档确定性控制库：R1 标称、R2 重载、R3 柔顺接触、R4 安全回退。每一档都按实际施加的指令做全分支反向追踪抗积分饱和，档位切换不会释放隐藏能量。否决激活或永久锁存切入 R4 时旁路 blend_alpha，blend = 1.0，紧急阻尼在第一个 tick 就生效，不受一阶无扰切换的延迟影响。

### 3. 未知流形与亚健康振荡

**问题。** 新装设备可能运行在标定流形之外：未建模死区叠加 4 Hz 安装模态是基准测试工况之一。结构振荡时，回路不能继续施加“看起来自信”的指令。

**传统与纯 AI 的失效。** 本基准所对比的固定阈值规则树（未额外内嵌显式流形距离/密度模型时）或模糊控制只编码决策边界，没有“距标定分布多远”的概念。物理规则树与原型分类器在主表 S1/S2 决策与 19.47 N 的 S3 接触峰值上一致，但在 OFF_MANIFOLD 工况下无法弃权，因为弃权需要特征点到已知运行区域的度量。

**机制。** 原型模型把 `ai_confidence` 作为距离型把握度输出。离开流形时把握度塌缩，触发低把握度主动弃权：1 kHz 内核记 GATE_VETO_LOW_CONFIDENCE，并以固定阻尼运行 R4，直到重新得到可信的正常工况。

### 4. 跨机台、批次与个体漂移，现场无重训算力

**问题。** 正向重载 +35%／+50%、交叉失配（J +40%，b -30%）、反向轻载 -25% 都会让设备偏离标称模型，而现场没有重训预算。

**传统与纯 AI 的失效。** 按周期重建标定档案假定每种工况都有数据集和一次训练；学习式动作头还需要额外标注。技术员手里只有力矩扳手和秒表时，两条路都走不通。

**机制。** 设计把两个对象正交解耦：冻结的 AI 流形拓扑负责定性工况，12 B 物理旋钮 `FieldTuning_t`（`gain_scale`、`damping_scale`、`safety_margin_scale`）吸收定量偏差。`auto_field_tune()` 在固定增益／阻尼网格上做 6 次受约束试验，只接受同时满足负载、接触与包络约束的候选，全程冻结分类器。

### 5. 100 ms 盲区、瞬态刺激与通信断联

**问题。** 100 ms 盲区属于 10 Hz 慢环的上下文更新：慢环每 100 ms 才看到新帧。刺激脉冲、换向边沿和传感器瞬态都落在这个窗口内，链路中断还会让旧指令留在执行器上。

**传统与纯 AI 的失效。** 更慢的监督扫描只会把盲区拉得更长。B2 的 1 kHz 连续动作头每毫秒读取快环状态，但其上下文特征 z 仍受 100 ms 慢环周期与传输时延约束。传输帧龄还可能被伪造或冻结；没有本地证据，回路分不清“设备安静”与“邮箱沉默”。

**机制。** 32 B 探针以 1 kHz 运行：三点中值滤掉单 tick 毛刺，级联高通提取宽频新息，攻击／释放包络把它变成无量纲残差。遇到计划内伪迹时，`blanking_active` 冻结探针全部状态并返回 0.0f，已经抬高的残差无法借消隐窗口维持否决。96 B 内核再叠加 25 ms 状态安全包络与相平面前瞻、独立残差否决，以及 `outer_seq` 本地时钟租约，冻结的传输帧龄无法掩盖停滞的邮箱。原生 HOLD 有界：超过 `max_hold_ticks`（参考配置 100 tick）后进入 GATE_SAFE_ZERO，清空积分器，并以 `max(u_slew_max_per_s * dt_s, 1 binary32 ULP(|u_prev|))` 的每拍步长把指令降到零。正常路径严格满足 `|u(k)-u(k-1)| <= u_slew_max_per_s * dt_s`；唯一书面例外是这条向零「单 ULP 保底」：仅当合法斜率预算小于一个可表示步长时启用，只减小幅度，绝不重新上电。

### 6. 裸机资源死限与事故追责

**问题。** 控制任务要在固定内存目标的 1 kHz 中断里运行，没有堆，也没有操作系统。事故报告还必须说明：是哪次决策、哪个根因把执行器放进了安全状态。

**传统与纯 AI 的失效。** Python 或推理运行时带来分配、调度抖动与不可追溯状态；没有持久证据的否决回答不了事后问题。

**机制。** 内核为 ANSI C99、零动态内存、静态定长状态，对象 text 在 `-Os` 下 6,452 B、`-O2` 下 7,608 B（GCC 4.9.2 TDM64，x86-64）。ABI 为 state/config/tuning/input/output 96/140/12/40/28 B，另加 32 B 探针。7 位 `fault_audit_bitmask` 记录延迟、残差流形外、低把握度、包络越界、NaN 损坏、HOLD 超时与永久锁存。累计 3 次安全／残差否决 episode 后永久锁死 GATE_LATCHED_SAFE；唯有人工调用 `Layered_AcknowledgeFaultLatch()` 才能解除锁存，在冷却期后恢复 episode 容限，并保留终身计数。

## 带宽与权限是两个独立选择

推理频率说明何时生成指令，指令是否可执行由另一组条件决定。完整架构必须规定状态估计、物理残差、执行器限制和恢复条件如何否决指令。

门控采用固定优先级：状态包络、残差、把握度，最后是原生延迟 HOLD。可观测状态是显式的——GATE_NORMAL、GATE_HOLD_LATENCY、GATE_VETO_OOD_RESIDUAL、GATE_VETO_LOW_CONFIDENCE、GATE_VETO_SAFETY_ENVELOPE、GATE_SAFE_ZERO 与 GATE_LATCHED_SAFE。帧龄始终可观测。驻留与恢复冷却约束重新启用时机，反向追踪抗积分饱和使每个非活动控制器都与实际指令保持一致，每 tick 的幅值与斜率限制属于执行器契约，正常路径严格满足 `|u(k)-u(k-1)| <= u_slew_max_per_s * dt_s`；GATE_SAFE_ZERO 的向零单 ULP 保底是唯一书面例外。

安全回退是一种明确的控制模态，其参考目标、阻尼与前馈权限必须按设备定义。原生 HOLD 保持的是上一条执行器指令，不是机械位置或生理状态，物理后果由设备适配层定义。内核 R4 以固定增益、零前馈朝已标定的安全零点调节；慢环决策损坏时，有效快速测量继续运行这条闭环控制律。

## 将现场适配落在可辨识的物理参数上

新设备可以沿用工况语义，同时具有不同的定量动力学。小样本建档确定工况原型与把握度阈值；随后冻结这份档案，在相同确定性保护下搜索有限的增益与阻尼调整。候选验收共同约束重载静摩擦误差、接触力与回退模态占比。

这样的标定记录能直接回答：哪些物理旋钮变化了，试验检查了哪些约束，跟踪性能如何变化。全新物理领域先定义信号、标称模型与控制库，再建立自己的语义档案。连续策略重训是另一项对照：采集目标机台动作标签后，分别测量标称精度、冻结迁移与恢复。

## 用实验拆开因果链

静摩擦模型必须能在指定积分步长下真实锁止；单边接触必须同时观察接触力与位置误差；未知柔性模态需要不读取故障频率的宽频残差探针；噪声、上下文延迟与接触刚度应能独立调节。

对照始终让基线保持满强度。B1 与 B3 共享完全相同的标称逆动力学前馈、抗积分饱和与限幅，B1 的 S2 结果仍是表中最低的原始误差。B2 动作头以 1 kHz 全速运行（40,000 次推理，快环状态零延迟），S3 接触力为全场最低的 12.52 N；但它没有显式积分器与物理门控，S2 误差偏大，S4 越界 589 tick。物理规则树与原型分类器在主表 S1/S2 结果和 19.47 N 的 S3 接触峰值上一致；它们的 S3 R3 占比相差 150 个 tick（93.49% 对 94.99%），表现为 S3/S4 RMSE 第三位小数的差异（0.075100 / 0.540437 对 0.069478 / 0.539985）。分层支路在 S4 记录 RMSE 0.539985 rad、TV 1545.01 N·m，而 B1 保持更低的 S2 原始误差、B2 保持 S3 接触力优势；这些观测共同定义了基准的解读方式。

跨语言回放闭合验证链。C99 独立回归 239 项全部通过、0 失败，120 行的 `gate_template.c` 独立自检输出 PASS。Python/C `--selftest` 回放 6,000 帧（R1 = 901、R2 = 900、R3 = 304、R4 = 3,895，含 ack 重武装随机对拍与 7→5→3→1→0 斜率归零），离散输出完全一致，连续指令差 max |du| = 0，binary32 逐比特精确相等。MATLAB/C `verify_core_equivalence` 覆盖 40,000 正常帧、40,000 损坏邮箱帧，以及 4 组各 40,000 帧的运行中非法旋钮注入，max |du| = 5e-9。另有 10,000 tick 的 `outer_seq` 租约回放，覆盖原生 HOLD → `SAFE_ZERO`、序号跌回 0 的损坏路径与冷却恢复，max |du| = 4.19e-8。Level-2 S-Function 回放 1,100 帧，7 路输出 max diff = 0.0。

## 面向受约束设备的通用接口

工业 WAAM 与 PLC 伺服在慢环识别工艺与负载工况，在快环完成过程调节与执行器约束。Edge VLA 在上层处理任务与环境语义，在下层完成力矩或阻抗闭环。aDBS／SCS 闭环神经调控把生物标志物与接口状态映射到设备定义的调节律、输出包络与时序限制。

三者是同一权限划分的并列实例。其他设备只要能定义可测状态、标称模型、明确回退与定量限制，就可以使用相同适配顺序。多通道分别持有控制状态、探针与时间戳，耦合约束由设备适配层处理。
